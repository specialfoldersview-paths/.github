# SpecialFoldersView - Paths Windows Uses on This PC

At a glance:
- Names of special folders on this install
- The path each name resolves to
- A read of this user, not a move
- No other computer and no published dump

## Where The Name Points

Windows calls some directories by a role: documents, downloads, startup, temporary files. SpecialFoldersView shows the path behind the role for this user. That helps when a program says it saved to Documents and you need the real folder. Open the path only if it is yours. Read it, copy the text into your notes if you must, and close the tool.

The list can include folders you rarely see, such as application data. Those files are often configuration. Do not delete them because the path looks obscure. The viewer is not a cleaner. It does not relocate a folder. Relocation is a separate Windows setting you should not change from a list you do not understand.

## This Profile

Paths under your user name are your profile. Paths under another name are another profile. Do not browse those. On a PC you administer, you still do not tour someone's documents out of curiosity. If a backup task needs your Documents path, copy that one line and stop.

An export of every special folder is a map of the account. Keep it private if you make it. You usually do not need the export. The one path on screen is enough.

## Do Not Clean From Here

Seeing AppData is not a reason to empty it. Programs store settings there. A cleanup guide that says to delete unusual folders is how a login breaks. Close SpecialFoldersView and leave the directories in place. Disk space is a different tool, aimed at files you know you created.

## One Path For The Job

If you came to find where Downloads is after you moved it, read that row and check the folder in Explorer. Confirm a file you expect is there. Then you know the path is current. A stale note of the path from last year may be wrong if you redirected the folder. The viewer shows the path now.

## Not A Remote Map

The tool reads this PC. It does not list special folders on a server you have not logged into with a file tool you are allowed to use. Do not treat a UNC path in the list as an invitation to a share you do not administer. If Explorer denies the folder, stop.

## Point The Backup There

If a backup still copies an old Documents path, it is copying the wrong place. Use the path on screen, confirm a real file in Explorer, and update the backup task. Do not delete the old folder until you have seen the files in the new one.

## Player Profile

SpecialFoldersView fits a check of where your Documents or similar folder really is. It does not fit deleting AppData, browsing another person's profile, publishing the path list, or moving system folders from the table.

## Help Desk

The folder looks empty? You may be in the wrong path. Check the row again in Explorer.
You wanted to move Documents? Do that in Windows settings you understand, not by deleting the old path first.
Another user's name appears? Do not open it.
A share path is denied? Stop. You were not granted that folder.
You wanted another PC? This list is local.

## Reader Notes

Come for one role and one path. Confirm it contains a file you expect. Then leave. The full list is a map you do not need to save.

Unusual folders are still part of the profile. Obscure does not mean unused. A cleaner and this viewer should not be open in the same hour.

If you redirected a folder last year, trust the path on screen today, then update your backup task to match. A backup of the old path copies an empty directory and misses the files.
